# Indigo Hive — One Piece Challenge

## About

This is an incomplete character browser that you will finish. It uses the external [AniList GraphQL API](https://docs.anilist.co/). Both screens currently use mock data.

No prior knowledge of React is expected. We want to see how you learn, understand and take ownership of your code. We will also consider code quality, including readability, organization, and modularization.

Treat this challenge as your first task at Indigo Hive.

## Tasks

1. **Connect the Home page:** replace the mock with the existing `useCharacters` hook. Fix pagination so changing pages loads different characters.
2. **Complete character details:** Replace the mock and display their name, image, description, age, date of birth, and AniList link.
3. **Improve the UI:** make the app more pleasant to use.
4. **Document your process:** use `README.md` to communicate with the reviewers. Explain how you approached the project, how many hours it took you, what was easy or difficult, and anything else you consider relevant. Add links to the materials you used in `REFERENCES.md`.

## General guidelines

Do not share your final code with classmates or ask other people to solve the challenge for you. You are welcome to discuss possible approaches with peers and share useful references. Contact us whenever you have questions or encounter problems.

## Tips

- We recommend using AI tools. Document how you used them, what you accepted or changed, and how you checked the results.
- Prioritize completing the requested work well before adding extras.
- Useful API documentation: [Character fields](https://docs.anilist.co/reference/object/character), [Character names](https://docs.anilist.co/reference/object/charactername), and [Pagination](https://docs.anilist.co/guide/graphql/pagination).

## Getting started and submission

Use **Fork** to create your copy, edit it in StackBlitz, then **Save** and share your project link.

- Change the name of the project to "Case Indigo Hive - Nome completo do candidato"
- Start with `src/pages/Home.tsx` and `src/pages/CharacterDetails.tsx`.
- Commands: `npm run dev`, `npm run lint`, and `npm run build`.
- Send the editor link with your fork to our email when finished. If you used git, you can also send the repo or .zip.
